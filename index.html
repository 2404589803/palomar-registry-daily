Sync and data boundaries

GitHub Actions 每日北京时间 10:15 发起同步；平台排队可能导致延迟。先读取全部分页并校验重复 ID、游标循环和数据修订号，再发布新的索引。

归档内容包含结果索引、最近记录、预览清单、源文件可用性、每条Results的版本索引和固定版本详情。辅助接口失败会记录在清单中；完整索引抓取失败则停止部署，保留上一次成功数据。

本站保存公开元数据与版本记录。Lean 源代码和完整证明构建环境仍以原Projects及固定提交为准。它不是 Palomar 官方网站。
