GitHub Actions starts a daily sync at 10:15 China Standard Time. All pages are validated before publishing.

The archive includes the results index, recent records, preview manifest, source availability, version indexes, and fixed-version records. Auxiliary failures are recorded in the manifest; a failed scan keeps the last successful data.
